# Real-site case protocol (Q1)

Each comparable real site must record:

- source: licensed real site, anonymized derivative, or synthetic
- permission to store drawings/screenshots
- input identity: original drawing digest, units, transform, local origin
- design conditions: vehicle, stall, obstacles, entrances, quotas, rules
- human reference layout and participants
- algorithm result: version, official layout, check status, time, failure class
- revisions: which objects changed and why

No licensed real CAD is included in this repository. Stage 二 therefore reports
synthetic round-trip evidence only and does not claim field effect.
